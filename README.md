# CLI Context Hub

A desktop workspace for managing large amounts of information concisely, built around AI CLIs (Claude Code, Copilot, Gemini, Ollama, Codex).

> **Status:** early development. This repository is being created by migrating and restructuring an existing prototype (HarnessHub). Nothing is usable yet.

## What it is

CLI Context Hub keeps terminals, sessions, handoffs and working files (contexts) in one place, so work started with one AI CLI can be continued by another without losing the thread.

## Goals

- **Concise management of high-volume information:** sessions with a handoff and a log, and contexts organized by topic.
- **Small core, everything else as extensions:** SVG viewer, embedded browser, MathNotes, Excalidraw and more will be installable from an extension store instead of shipped in the core.
- **Scalable code:** clear code standards and module boundaries.
- **Automated tests** across the whole application.

## Roadmap

1. Import the prototype and rename it to CLI Context Hub
2. Code standards and architecture
3. Extension system
4. Extension store
5. Automated tests and CI
